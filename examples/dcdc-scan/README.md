# DC-DC 150点近场扫描

来源：`scan-20261028-230511`，2026年10月28日。150个位置，每点3帧，共450帧。扫描坐标为操作员观察下的 left_mm（向左）和 away_mm（向远离操作员），起点(0,0)，70×44 mm范围，15列×10行，蛇形路线。X为0至70 mm、间距5 mm；Y为0至40 mm间距5 mm，最后一行为44 mm。控制器+X向左、−Y向远处，换算比例来自近似尺量，网格间距不代表定位精度。

|材料|内容|
|---|---|
|points.csv|150点原坐标、分频段RMS、最高观察频点；幅度单位为相对ADC码|
|spectra.csv|150×2049行单边频谱，频率单位Hz，INA/INB PSD单位ADC码²/Hz|
|spectra.npz|相同数据的压缩表示：frequency_hz [2049]，coordinates_mm [150,2]，psd_codes2_per_hz [150,2049,2]，通道顺序INA、INB|
|raw/|起点(0,0)、报告代表峰值(40,30)、终点(0,44)的9帧原始采样及原频谱、通道映射|
|session.json|扫描范围、通道、帧长、标称采样率与配置，已移除本地路径和控制器调试设置|

采样配置：标称50 MS/s，每通道每帧4096样本，频率间隔12207.03125 Hz，单边频谱2049点。每个原CSV含16384个打包原始时钟记录；capture_word[31:0]为十六进制 packed32_v1 数据，不能把每行当作一个独立的50 MS/s样本。具体有效相位关联为INA=1、INB=3，仅适用于记录的采样构建。原始通道码编码保留14位补码假设，外部IO时序未完成独立签核。

前端链路：近场探头→有源放大→低通→ADC INA；到点等待0.5 s，每点3帧，频谱在线性功率域平均。记录中的增益控制1.82 V为操作员报告，无硬件回读。频谱保存至25 MHz用于完整保留原计算结果；20–25 MHz接近奈奎斯特与滤波边缘，21.9–25 MHz在部分展示中被隐藏，不应理解为已验证有效带宽。报告的(40,30)代表0.2–3 MHz与3–10 MHz频带峰值，而非所有频率、所有工况的最大点。

这些数据用于相对分布观察，没有绝对场强、EMC认证、探头空间响应或机械精度校准。本目录未使用板面拉伸坐标、插值背景或STM32模拟EMI。完整450帧数据包见[首批材料Release](https://github.com/tongzeyu-crypto/fpga-pcb-multimodal-inspection/releases/tag/materials-20261103)。

解码与频谱核对：packed32_v1 的低14位为通道码，位15–16为相位；取相位1得到本次INA的4096点，按14位补码假设换算。每帧去均值，使用周期Hann窗，单边PSD按 `|rFFT(x*w)|² / (fs*sum(w²))` 归一化，除DC与奈奎斯特外加倍，三帧在线性功率域平均。本次三个公开代表点重算与归档频谱一致（最大绝对差小于1.1e-19 ADC码²/Hz）；这只验证数字处理一致性。
