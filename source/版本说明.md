# 正式提交版

本版包含本次实板验证使用的 FPGA 位流、HDF、设备树、驱动、ARM 主程序、模型权重，以及程序源码、原始数据和必要验证摘要。已去掉旧测试可执行程序、失败构建目录、详细调试日志、临时传输工具和中间输出。

- 电脑展示：双击 `start_demo.cmd`。
- 板端展示：配套硬件和驱动临时加载后，运行 `sh start_board_demo.sh --display /tmp/pcb-trial/display --tag 0`。
- 完整显示素材与调用方法见 `docs/实板演示记录-20261103.md`；硬件产物放在 `hardware/`。
- 文件核对：`python tools/verify_delivery.py`。

扫描页继续使用模拟运动和历史数据回放；补帧 CNN 已通过实际 PL 运行验证。完整实时采集和机械闭环未验收。原有自启动镜像没有改动。本版不会自动启动 JTAG 服务、远程调试或传输接收程序。

Python 基础库、两个电脑演示程序和板端驱动均为运行依赖，已保留。详细调试记录和回退程序保存在独立的“调试版”。
