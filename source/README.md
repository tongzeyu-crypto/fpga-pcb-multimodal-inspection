# 桌面 PCB 多模态检测系统

本版固定依据用户指定的《技术文档2.docx》实现。原文未修改，来源指纹见 `resources/technical-document2-contract.json`；逐条源码及验证对应见 `docs/报告实现对照.md`。

PDP3 将原始 ADC 相位筛选、双通道提取、4096 点 Hann FFT、三帧平均 PSD、频段 RMS，热像解码／热点／伪彩色，以及共享图像算子接入现有主程序。配准和帧融合复用 PL 卷积核；PS 执行调度、几何变换、规则判断、重投影与最终像素融合。正式路径没有设备失败后的软件数值回退。

双击 `start_demo.cmd` 打开原界面，查看扫描演示、原有多模态视图和神经补帧。本机入口使用真实历史输入和已核验 RTL 结果回放，运动为模拟。真实扫描入口通过 `--live-scan --motion-config <已校准配置>` 接入 GRBL 和新鲜 ADC，默认采用 70×44 mm、150 点路线，范围和 X/Y 步距可在界面修改（最多 1024 点），需点击开始才移动。

本版完成源码集成、八个 ARM 程序编译、算子和网络 RTL 仿真、整机位流生成及电脑界面验证。整机核心 62.5 MHz，时序 WNS +0.653 ns、WHS +0.009 ns；当前新版本未上板验证。现有自启动镜像未改动。构建方式和运行条件见 `docs/构建与运行.md`。
