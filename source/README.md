# Zynq-7020 正式提交版

本目录包含PS/PL源码、模型训练与剪枝量化工具、INT8权重、图形引擎、ARM程序、设备驱动、硬件产物和验证记录。2026年11月3日完成实板RAM启动、配准与帧融合PL推理一致性检查、HDMI显示和主程序功能演示。

## 运行入口

- 电脑演示：双击 `start_demo.cmd`，或运行 `python -m runtime.run_board --demo`，浏览器打开 `http://127.0.0.1:8698/`。
- 板端演示：加载配套位流、设备树和驱动，运行 `sh start_board_demo.sh --display /tmp/pcb-trial/display --tag 0`。
- 原始数据处理：`runtime.run_board --bundle`校验来源与哈希，复算图像、温度与频谱并生成显示资源。
- 文件核对：`python tools/verify_delivery.py`。

板端图形、AI和AXI核心为62.5 MHz，HDMI参考为100 MHz，ADC原始域为200 MHz。1280×720源画面放大至1920×1080、30 Hz输出。原自启动镜像保留，当前程序和资源从RAM运行。

## 功能与实现

|模块|实现|
|---|---|
|配准网络|残差CNN、结构化剪枝、W8A8/QAT；共享PL引擎执行任务1|
|神经帧融合|深度重投影、像素融合CNN、INT8权重；共享PL引擎执行任务2，PS完成重投影及像素融合|
|图形显示|PL光栅化、深度、纹理与HDMI；单层扫描输出、独立合成帧缓存|
|扫描演示|ARM六点路线、到点报告检查、停稳等待、每点三帧关联、选点、停止、重跑与导出；采用模拟运动和历史数据|
|数值处理|PS执行4096点周期Hann PSD、双通道三帧功率平均、热像解码与原矩阵查询|
|小型PL算子演示|64点DFT、16×16热像转换/阈值计数、共享灰度量化；独立RTL核与已核验XSim结果回放|
|数据输入|Zynq原始记录或采集入口，外部正常参考RGB与预建几何；页面随输入条件启用|

实板配准任务9个INT8输出、帧融合任务3600个INT8输出均与整数参考一致。主界面呈现神经生成中间帧后继续真实渲染，单次准备及显示记录约1.34 s。扫描页完成六点、十八帧关联与21次已核验结果回放。

## 目录

`runtime/`为PS程序、采集与原生界面，`rtl/`为共享AI与ADC核，`graphics/`为图形源码，`models/`为训练/剪枝/INT8模型，`demo/`为独立算子和扫描调度演示，`drivers/`为驱动与设备树，`hardware/`为位流及HDF，`tools/`、`tests/`、`evidence/`为构建、测试及记录。

操作与分工见[构建与运行](docs/构建与运行.md)、[功能清单](docs/功能清单.md)、[实板记录](docs/实板演示记录-20261103.md)和[验收记录](docs/验收记录.md)。本次文字修订统一了版本说明和打包工具，算法、RTL、模型权重、二进制及测量记录保持交付版本。
