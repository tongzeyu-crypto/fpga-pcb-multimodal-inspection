# 自启动服务配置

本目录保留随程序包提供的 systemd 服务定义、SysV 启动脚本与运动参数模板，供审阅和重建使用。提交方提供的2026年11月4日《对照分析报告》记录本版服务已部署、启动镜像已更新，并完成上板自启动流程验证。

服务要求 Python 3、NumPy、OpenCV、匹配的内核模块与PDP3位流。设备节点及版本不匹配时会报错，不切换到软件数值回退。运行目录示例为 `/opt/pcb-detection`，运行结果写入 `/tmp/pcb-detection`。

`motion.json` 中的端口、方向、比例和原点需与实际平台一致。`origin_confirmed` 默认值为 false；配置为实际确认值后，操作员仍需在界面点击开始扫描。启动服务本身不会开始移动，也不会自动回零或解除控制器报警。
