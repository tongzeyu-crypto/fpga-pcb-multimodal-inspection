# 候选自启动配置

这里提供独立镜像使用的 systemd 服务源文件和 pcb-detection.init（SysV 候选脚本），当前没有安装、启用服务，也没有修改开发板现有自启动镜像。

候选镜像需要 Python 3、NumPy、OpenCV、匹配的内核模块与候选位流。服务在设备节点存在后启动主程序；原生图形驱动核对来源标记，CNN 接口核对模型 ABI 与硬件版本，PDP3 接口核对 `0x50445033` 和 4096 字容量，ADC 接口核对版本、50 MHz 采样参数及锁定状态。任一不匹配会报错，不切换到软件计算。

路径以 `/opt/pcb-detection` 为例，运行结果写入 `/tmp/pcb-detection`。此文件不包含加载位流、写入闪存、修改启动参数或启用服务的命令。

`motion.json` 中的端口、方向、比例和原点需与实际平台一致。`origin_confirmed` 默认为 false；配置为真实且经确认的值后，操作员仍需在界面点击开始扫描。启动服务本身不会开始移动，也不会自动回零或解除控制器报警。
