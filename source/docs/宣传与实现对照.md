# 宣传与实现对照

原参赛技术报告不修改。本表针对本独立提交版源码和本轮证据，不覆盖开发板原有自启动镜像。

| 表述/功能 | 本轮可以支持的准确表述 | 仍不能支持的表述 |
|---|---|---|
| Zynq 运行 | ARM 本地采集/处理/调度源码、交叉编译程序，PL 图形及共享计算源代码 | 本提交版已经上板或整机验证成功 |
| AI 配准 | 已训练固定机位小扰动残差 CNN；有通道剪枝、量化和 PL 整数逐层验证 | XoFTR 已部署、通用未知 PCB 精度、独立实拍配准准确率 |
| AI 帧生成 | 完整深度重投影 + 已训练像素融合 CNN，网络实际参与 RGB 合成；主界面可运行补帧/网络关闭对照；原生源码提交 PL 任务，最多插一帧 | 已测得板上 FPS/延迟提升，重复旧帧算新帧，无损合成 |
| 剪枝 | 提供结构化通道清单及实际参数数量变化 | 参数减少等于整机速度或功耗同比改善 |
| INT8 | 两模型真实权重、校准尺度、整数参考、RTL 一致性记录 | 无精度损失；量化导致的退化必须看验收数值 |
| RGB 待测图 | 来自 Zynq USB 采集或保留的真实 Zynq 原始回放 | 把 Windows_USB_DIRECT 缺陷图作为板端采集 |
| 热像 | 已有真实 Zynq 双平面原始记录，温度按 uint16/16−273.15 复算，查询逆映射原矩阵 | 没采到热像；绝对测温精度已标定；融合提升探测器真实分辨率 |
| ADC/EMI | 完整原始 ADC 帧、ARM 4096 点 FFT、三帧线性功率平均、频段积分；新增 AXI 帧缓冲源码 | 原有 4096 点 FFT 已迁入 PL；ADC 外部 IO/模拟带宽已签核；校准场强 |
| PL/PS 功能演示 | 主程序及原有界面已加入六点扫描调度，显示小型 PL 核的 64 点 DFT、热像温度/阈值热点计数、共享灰度量化的已核验结果回放；模拟运动和历史采样关联离线跑通 | 新 PL 核已加入原整机 bitstream；真实机械闭环、同步采样或全部图像预处理已上板验证 |
| 三维 EMI | 单高度扫描的机械空间—频率可视化；缺少机械到 RGB 标定时不叠加到器件 | 已测完整三维电磁场、自动把电磁峰值和热点对齐 |
| 采集批次 | RGB/热像顺序采集；已有 ADC 是另一日期扫描，关联同一审核包但明确为不同批次 | 硬件同步、多模态同时采集的一次快照 |
| 3D 模型 | 导入的预建网格、封装高度/UV/材料先验，在此基础上生成叠加 | 任意未知 PCB 的实测三维重建、实测器件高度 |
| 图像缺陷 | SIFT/RANSAC、局部灰度背景校正、形态学/连通域可见变化候选 | 内部虚焊、电气通断、IPC 验收、已验证缺陷准确率 |
| 两板页面 | 八个主要页面和鼠标交互源码保留，离线渲染和切换检查；缺输入显示等待 | STM32 模拟频谱变为实测；没有参考图也自动显示历史缺陷结果 |
| 相机型号 | USB 采集格式和实际尺寸有记录 | USB 接口/分辨率足以证明传感器为 IMX577 |
| EMC | 相对 ADC code²/Hz、RMS ADC codes，含未签核边界 | EMC 合规、替代暗室或校准近场强度测量 |

后续视频稿若使用“AI 自动配准、剪枝量化、硬件帧生成”措辞，应补充“独立提交版源码/离线验证”和整机实现、实板验证的实际状态。技术报告已有 SIFT/RANSAC 规则算法和未来整合的保守表述无需擅自改写。
