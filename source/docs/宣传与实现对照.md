# 功能与实现路径

|功能|实现路径|
|---|---|
|Zynq运行|ARM程序与双驱动，RAM启动，PL图形及共享计算引擎|
|AI配准|固定机位残差CNN，结构化通道剪枝、W8A8/QAT；PL任务1输出几何修正与可信度|
|神经帧生成|深度重投影与已训练像素融合CNN；PL任务2生成区域权重，PS完成RGB合成|
|INT8|模型权重、校准尺度、整数参考、RTL逐层对照及实板输出一致性|
|RGB/热像|Zynq USB原始记录；热像按uint16/16−273.15复算，查询回映原矩阵|
|ADC/频谱|完整原始帧、PS 4096点FFT/PSD、双通道三帧平均与频段积分|
|扫描展示|ARM六点调度、模拟控制器、历史原始采样关联、已核验RTL结果回放|
|小型PL算子|独立64点DFT、温度转换/阈值计数与灰度INT8量化核|
|三维模型|预建网格、封装几何及照片纹理，提供板卡位置和图层关联|
|外观分析|SIFT/RANSAC配准、局部灰度校正、形态学与连通域候选|
|近场单位|PSD为相对ADC码²/Hz，频带RMS为相对ADC码|

配准训练使用既有DC-DC来源的几何增强；帧融合训练使用预建几何渲染监督。模型评价按对应数据与视角集合解释。RGB/热像与ADC保留各自采集批次，机械坐标与图像坐标通过配置关联。

实板流程、显示时钟、输出格式和逐项记录见[实板演示记录](实板演示记录-20261103.md)。
