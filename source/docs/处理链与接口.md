# PDP3 处理链与接口

## 处理分工

| 链路 | PL | PS |
|---|---|---|
| ADC／频谱 | 原始字标志、心跳、相位计数及过载检查；相位 1／3 双通道提取；去均值、周期 Hann、4096 点 FFT、单边功率、三帧平均 PSD、指定频段 RMS | 设置采样率／频段；顺序提交双通道和三帧；保存位置、帧号、来源和结果索引；定点单位反量化 |
| 热像 | 完整 256×192 温度面 Kelvin16→毫摄氏度，极值／热点数量／峰值索引，整数 Jet 伪彩色 | USB 读取、矩阵组织、几何变换与查询关联 |
| 图像 | 双线性缩放、3×3 Gaussian、Sobel 幅值、参数归一化、RGB 灰度／量化、差分阈值、3×3／5×5 腐蚀膨胀 | 图块／邻域地址组织，SIFT/RANSAC、局部背景校正、连通域与元件／引脚规则 |
| 神经网络 | 共享 INT8 卷积、池化、输出层 | 任务控制，几何映射门限、Sigmoid、权重插值、重投影与像素合成 |

一个 FFT 核依次处理通道和帧。图像／热像使用同一 4096×64 工作缓存分块；FFT 功率累积使用另一个缓存。CPU 组织 resize 的采样地址和卷积邻域，插值、卷积、梯度与归一化算术由 PL 执行。未将 PS 的几何和连通域分析算作 PL 算子。

PSD 使用 `P*N²*2^36/(Fs*window_energy_Q28*frames)` 得到 Q40 值；积分后以整数平方根得到 RMS Q16。输出为 2049 个自然频率顺序频点。PS 对 Q40／Q16 仅做单位反量化；显示资源生成器读取来源与哈希匹配的结果文件，不重新执行 PS FFT。

## 寄存器

基地址 `0x43CC0000`，跨度 64 KiB，身份 `0x50445033`，最大块 4096 字。驱动独占设备，客户端核对完成代次和输出数量。

| 字节偏移 | 用途 |
|---|---|
| 0x00 / 0x04 | 启动1／中止2；busy bit0、done bit1、error bit2 |
| 0x08 / 0x0C / 0x10 | 身份／任务／本块输入字数 |
| 0x14 / 0x18 | 热点或差分阈值／算子模式 |
| 0x1C / 0x20 | 热像量化基值／移位 |
| 0x24..0x30 | 最小温度、最大温度、峰值全局索引、热点数量 |
| 0x34 / 0x38 / 0x3C | 完成代次／4096 容量／FFT 累积帧数 |
| 0x40 / 0x44 | 窗能量 Q28 的低／高字 |
| 0x48 / 0x4C / 0x50 | 全局块偏移／温度像素计数／接口修订号 |
| 0x54 / 0x58 / 0x5C | 采样率／频段数最多8／当前输出数量 |
| 0x60 / 0x64 / 0x68 | 归一化分母／伪彩色温度下限／上限 |
| 0x6C / 0x70..0x7C / 0x80 | ADC 总字数／四相位计数／错误码 |
| 0x100+8k / 0x104+8k | 第 k 段起始频点／结束频点（右端不含） |
| 0x180+4k | 第 k 段 RMS Q16 |
| 0x1000..0x4FFF | 4096 个 32 位输入槽 |
| 0x8000..0xFFFF | 4096 个 64 位输出槽，低字在前 |

任务1 FFT累积、2温度、3灰度／量化、4ADC提取、5PSD／RMS、6缩放、7Gaussian／Sobel／形态学、8归一化、9差分阈值、10伪彩色。具体模式和错误编码以 `demo/rtl/pcb_demo_core.sv`、`runtime/pl_compute.cpp`、`runtime/pl_image.cpp` 为准。复位／中止会清除累积有效性，不把上次完成当作新结果。
