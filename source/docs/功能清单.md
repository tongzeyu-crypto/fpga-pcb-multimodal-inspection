# 功能与入口

| 功能 | 提交实现 |
|---|---|
| RGB／热像二维与三维融合 | 原有模型、视图、原图与温度查询；PL温度／伪彩色；PL共享配准输入与CNN残差，PS几何映射 |
| EMI 地形、频率立方体、按点／频段查询 | PL双通道4096FFT、三帧平均PSD与RMS；完整频谱文件及原有显示 |
| 可见异常候选 | PS SIFT/RANSAC和背景校正；PL差分、阈值、腐蚀膨胀；PS元件存在性、标注引脚连通和独立亮金属区域规则，保留两图坐标 |
| 真实机械扫描 | `run_board --live-scan` 或 `board_demo --live-scan`；GRBL实际状态、150点路线、0.5秒停稳、ADC新帧、异常停止 |
| 电脑功能演示 | 原界面、历史输入与RTL结果回放、明确模拟运动；独立于真实扫描模式 |
| 学习式过渡帧 | 横／纵运动、深度边缘、有效区域→共享PL网络→权重插值→候选与上一完整帧像素融合 |
| 候选自启动 | 未安装的systemd源配置；设备和版本不匹配报错，运行记录写RAM |

本版完成离线数值、原界面和整机实现验证；传感器连续采集、真实运动与HDMI的当前版本实板验收尚未执行。报告原有历史测量不由这些离线检查替代。
