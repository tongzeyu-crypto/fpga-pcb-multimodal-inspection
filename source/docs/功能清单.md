# 功能清单与页面输入条件

本表描述提交源码的能力和当前离线证据。页面能够生成不代表已在开发板显示；驱动能交叉编译也不代表传感器实测或整机可用。

| 模式 | 页面 | 正式输入条件 | 当前交付状态 |
|---:|---|---|---|
| 0 | 三维热像融合 | 合规 RGB、热像、预建几何、成功的 PL 配准结果 | 真实 DC-DC 原始回放 + 明示离线 INT8 后端已生成参考渲染；正式模式要求 PL，不静默用电脑替代。EMI 缺机械标定时不叠到模型。 |
| 1 | 二维热像融合 | 同上，使用板面先验 | 参考渲染通过；绝对配准精度未独立标定。 |
| 3 | EMI 地形 | 原始 ADC 三帧/点，至少 2×2 的完整机械网格 | 150 点真实回放复算；使用机械坐标，隐藏没有空间标定的 RGB 模型。 |
| 6 | 频率立方体 | 同上 | 空间—频率可视化，保留原始全频信息；不是实测三维电磁场。 |
| 12 | 可见缺陷候选 | 外部正常参考 RGB + Zynq 待测 RGB，配准质量通过 | SIFT/RANSAC、局部灰度校正、形态学、连通域；已测无变化自比较和显示发布，没有真实缺陷准确率。缺参考时等待。 |
| 13 | 原始 RGB | Zynq RGB；参考 RGB 可选 | DC-DC 原图哈希/尺寸保存，界面预览不替换原始 JPEG；没有把待测图复制到参考栏。 |
| 14 | 原始热像 | Zynq 双平面 uint16 原始文件 | 256×192 原矩阵复算及查询 API；鼠标温度查询的板端交互未验证。 |
| 15 | EMI 测点与频谱 | Zynq 原始 ADC 记录和机械位置 | 450 帧复算、三帧线性功率平均、2049 频点；部分显示/积分频段截止 21.9 MHz，不删除原始高频。 |
| 16 | 扫描演示 | 显式 `--demo` 入口；六点历史原始子集、已核验的 RTL 返回值 | 已合入主程序与原生界面；模拟移动、到点报告检查、停稳等待、每点三帧关联、选点、重跑、清空、导出离线通过。PL 示例为 64 点 DFT、热像转换/阈值计数、共享灰度量化，未加入原整机 bitstream。 |

STM32 没有经本轮确认的合规原始输入，因此八个页面均保持等待。真实 RGB 单模态或完全无输入时，相关页面按模态独立启用/禁用，已做子集回归。不能以 DC-DC 或原有 STM32 模拟数据补齐。

其他历史模式（模拟时间变化、前后场景差异等）不作为正式入口；场景选择固定为当前实测扫描，不伪造第二次扫描或时间序列。

| 链路 | 源码位置 | 已验证 | 仍有边界 |
|---|---|---|---|
| 数据来源与切板 | `runtime/capture_bundle.py`、`service.py` | 哈希、来源拒绝、路径限制、切板清空、缺输入等待 | 历史元数据不是设备数字签名。 |
| USB 采集 | `camera_stream.c`、`camera_capture.c`、`capture_live.py` | C 程序 ARM 交叉编译，原始回放复算 | 本轮未接相机；实时新批次与标定关联未上板验证。 |
| ADC 读取 | `rtl/pcb_adc_capture.sv`、`pcb_adc_axi.sv`、`runtime/pcb_adc.cpp`、`drivers/pcb_compute.c` | 冻结帧/跨时钟/溢出/代次仿真；用户程序 ARM ELF；新增 `.ko` 已交叉编译 | 模块未加载；唤醒稳定时间、外部 IO 和模拟带宽未签核。 |
| 数值处理 | `runtime/numerics.py` | 热像差 0；ADC PSD 与旧结果最大差约 6.51×10⁻¹⁹ | 一致性不是物理精度认证；补码解释未校准为电压。 |
| 残差 CNN | `models/registration`、`runtime/registration.py`、`pcb_ai.cpp` | 训练/剪枝/微调/QAT/INT8，实际权重 RTL 逐层一致 | 只有一组真实来源，64×48 网格增强误差不等于绝对实拍误差。 |
| 神经像素融合 CNN | `models/frame`、`runtime/display/driver/full_ai_frame.h` | RGB 重建监督训练；网络权重参与像素合成；12 个保留视角、整数/RTL、网络关闭对照通过 | 只验证小角度、有限渲染用例；部分画质指标退化，未测板上速度和图层实际显示。 |
| 原生图形与深度 | `graphics`、`runtime/display` | 深度开关、末行裁剪仿真；24 个页面切换参考状态 | 完整实现状态独立记录；物理 HDMI/鼠标未在本版验证。 |
| 机构控制 | `grbl_control.c`、`grbl_guard.h` | 源码保留、ARM 交叉编译 | 本轮没有运行运动、回零或扫描；不把采集/运动/UI 当作已验收的连续实时闭环。 |

正式复算入口为 `python -m runtime.run_board`。内部显示后端的资产文件是新批次复算输出；不得把历史派生目录直接作为正式业务输入。电脑上的训练、仿真、渲染参考与截图仅用于开发证据。
