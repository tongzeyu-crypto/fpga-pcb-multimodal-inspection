# 功能清单与输入条件

系统由数据采集与来源校验、PS数值处理与调度、PL推理与图形显示组成。实板运行记录见[实板演示记录](实板演示记录-20261103.md)。

|模式|页面|输入与处理|
|---:|---|---|
|0|三维融合|RGB、热像、预建几何与配准映射；PL绘制模型和纹理|
|1|二维融合|RGB结构、热像原矩阵与板面坐标映射|
|3|EMI地形|机械位置、每点三帧ADC记录；PS复算PSD和频段积分|
|6|频率立方体|机械位置与完整频率轴，空间—频率关联显示|
|12|可见缺陷候选|正常参考RGB、待测RGB及配准；SIFT/RANSAC、局部校正与形态学分析|
|13|原始RGB|Zynq JPEG及其来源、尺寸与哈希|
|14|原始热像|256×192双平面uint16数据，温度复算与原矩阵查询|
|15|EMI测点与频谱|150点、450帧、2049频点；三帧线性功率平均|
|16|扫描演示|六点模拟路线、历史采样、停稳与帧关联、已核验RTL结果回放|

页面根据对应输入条件启用。加载正常参考图后启用外观对照；温度查询回映至原矩阵；机械频谱按原始毫米坐标组织。切换板卡时同步切换或清空资源，输入不足时显示等待状态。

|模块|源码位置|处理路径|
|---|---|---|
|来源管理|`runtime/capture_bundle.py`、`service.py`|板卡/采集ID、原始哈希、格式与标定关联|
|USB采集|`camera_stream.c`、`camera_capture.c`、`capture_live.py`|ARM Linux设备读取与原始文件保存|
|ADC读取|`rtl/pcb_adc_capture.sv`、`pcb_adc_axi.sv`、`runtime/pcb_adc.cpp`|冻结帧、跨时钟缓存、代次/溢出与PS读回|
|完整数值处理|`runtime/numerics.py`|PS热像解码、4096点周期Hann PSD与频段积分|
|残差CNN|`models/registration`、`runtime/registration.py`、`pcb_ai.cpp`|训练、通道剪枝、QAT与PL整数推理|
|像素融合CNN|`models/frame`、`runtime/display/driver/full_ai_frame.h`|PL生成融合权重，PS重投影和RGB合成|
|图形与显示|`graphics`、`runtime/display`|PL图形、深度、纹理与单层HDMI扫描输出|
|运动接口|`grbl_control.c`、`grbl_guard.h`|GRBL协议与状态检查；扫描演示使用模拟控制器|

小型算子演示使用独立PL核和XSim结果；整机位流承载图形、共享AI与ADC接口。显示合成像素与传感器分析输入分别保存。
