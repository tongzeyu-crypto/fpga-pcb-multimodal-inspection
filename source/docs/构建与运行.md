# 构建与运行

## 本机演示

双击根目录 `start_demo.cmd`，或执行 `python -m runtime.run_board --demo --no-browser`。默认地址 `http://127.0.0.1:8698/`；依赖见 `runtime/requirements.txt`。本机入口不访问板卡或滑台。

## 板端主程序与扫描入口

需要与本版匹配的位流、设备树和驱动，设备节点为 `/dev/pcb-gfx3`、`/dev/pcb_ai`、`/dev/pcb_adc`、`/dev/pcb_demo`。PDP3 身份为 `0x50445033`，旧 PDP2／r6 硬件不能运行本版计算接口。

完整原始包处理并启动原界面：

```sh
python3 -m runtime.run_board --bundle data/raw/dcdc.bundle.json --state /tmp/pcb-submission --tag 0
```

此入口需要目标 ARM 版 NumPy／OpenCV。JPEG、SIFT、几何和规则分析在 PS，谱、温度、共享图像算子和 CNN 进入 PL；计算结果经来源与哈希核对后用于生成显示资源。

接入真实扫描时增加 `--live-scan --motion-config <实际配置文件>`。配置格式见 `resources/autostart/motion.json`。端口、方向、比例、原点必须是实际确认值。操作员点击开始后才生成运动；没有自动回零、解锁或默认启动扫描。暂停保留已完成点，停止并清空开启新的结果编号。

仅使用已生成场景的精简板端入口：`sh start_board_demo.sh --display /tmp/pcb-trial/display --tag 0`，也接受上述真实扫描选项。该入口提供精简镜像需要的纯 Python 标准库，计算由随包 ARM 程序完成。显示快照与运行状态写 RAM 路径。

## 重建与验证

- `tools/build_arm.py`：八个 ARM 程序；`demo/tools/build_client.py`：同源计算客户端。
- `tools/build_kernel.py`：仅向独立 Linux 构建机传输驱动／设备树并编译，不接触开发板。
- `demo/tools/verify_full_pipeline.py`、`demo/tools/verify_report_pipeline.py`：实际 AXI 频谱、热像与新增算子验证。
- `tools/verify_rtl.py`：两个模型的逐层 PL 仿真。
- `tools/build_combined.py`：单图形引擎、CNN、ADC、PDP3 和 HDMI 整机；核心62.5 MHz、HDMI参考100 MHz、ADC内部200 MHz。
- `tools/build_demo_host.py --extend-glyphs`、`tools/verify_demo_integration.py`、`tools/verify_scan_ui.py`、`tools/verify_frame_demo.py`：原界面、150点路线和神经展示。
- `tests/report_contract_test.py`：隔离进程的 GRBL 协议、采样关联、异常停止及可见缺陷规则测试。
- `tools/verify_processing_consumers.py`、`tools/verify_delivery.py`：结果消费与交付来源一致性。
