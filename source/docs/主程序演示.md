# 主程序与原有界面的功能演示

双击根目录的 `start_demo.cmd`，或运行 `python -m runtime.run_board --demo`。
浏览器入口默认是 http://127.0.0.1:8698/ 。关闭运行窗口或按 Ctrl+C 结束服务。
启动器只启动本机离线服务，不打开串口、网络开发板、JTAG、摄像头或 FPGA 设备，也不操作现有自启动镜像。

在原有界面左侧点击“扫描演示”，再点击“开始 / 重新演示”。浏览器上方也有同名控制。
六个点按蛇形路线执行模拟移动、控制器到点报告检查、0.7 秒停稳等待、每点三帧历史 ADC 原始记录和测点关联。
已完成点变色，右侧可以选择结果点；“停止并清空”会取消当前工作并清除本次结果。
点击“导出记录”下载本次运行事件、坐标、帧来源、输入哈希和计算结果。
重新开始生成新的运行标识和记录，频谱显示与本次已完成测点绑定。

同一个界面继续提供三维融合、二维融合、EMI 地形、频率立方体及原始 RGB、热像、EMI 页面。
STM32 缺少原始输入时仍显示等待；焊接缺陷页缺少参考或结果时仍显示等待。
这些页面从原始数据重新生成显示资源；新增演示页读取小型 PL 核经过逐值核验的 XSim 结果，二者在程序中明确区分。

新增演示页使用原有 `FullScene`、`FullDraw`、固定点渲染器、导航和鼠标命中规则，画布为 1280×720。
新增 PL 源码、输入和离线证据已合入主程序的 `demo/` 目录，PS 调度从主程序入口启动。
Windows 的 `bin/demo_reference.exe` 用来显示原生界面的 CPU 参考画面，界面速度不能作为 FPGA 性能。

新增 PL 示例包括 64 点实数 DFT 的正频率功率、Kelvin×16 到毫摄氏度的温度转换及阈值热点计数、RGB 与热像共用的灰度 INT8 量化。
显示采用 16×16 子采样；热点阈值为 40°C，当前历史样本最高约 38.975°C，因此热点数量为 0。
此处的频谱不等同于原有 4096 点 Hann FFT/PSD；热点计数不包含连通区域分析；共享量化不包含全部配准预处理。

主程序的软件流程和界面已合并。扫描页使用独立算子核的已核验XSim结果；整机位流运行图形、共享AI与ADC接口，原启动镜像保留。
整机与独立算子核分别提供对应时序和功能记录。
板端主程序、HDMI与共享AI推理的实板记录见[实板演示记录](实板演示记录-20261103.md)；扫描页采用模拟运动和历史采样。

如果在其他 Windows 机器运行，先安装 Python 3.10+ 和 `runtime/requirements.txt` 中的依赖。
`demo_reference.exe` 已随演示包提供，运行不需要编译器；重编译入口为 `tools/build_demo_host.py`。
完整源码包从 `data/raw/dcdc.bundle.json` 加载原始数据。临时计算和扫描记录写到新的临时目录，启动时会显示其路径。
开发目录可指定 `--demo-work E:/PCB-Zynq-Build/my-demo-run`；此路径需使用英文字符。

主界面现已新增“神经补帧”入口，可实际执行 INT8 网络，播放新生成的中间画面并与关闭网络对照；详见 [神经补帧](神经补帧.md)。
