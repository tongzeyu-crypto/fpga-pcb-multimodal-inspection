# 原界面功能展示

双击 `start_demo.cmd`。本机扫描页使用六个实际历史测点，每点三帧4096点数据，以已通过AXI核验的结果回放计算链。运动位置由明确标记的模拟器提供，停稳等待0.5秒。暂停保留结果，停止并清空取消任务；再次开始使用新的采集会话编号。

真实扫描通过同一个主程序和界面接入GRBL位置回报及新鲜ADC。默认路线为70×44 mm、15×10点，常规5 mm、末行4 mm；界面可修改范围和X/Y步距，支持最多1024点结果选择。调度检查新鲜Idle与目标位置，停稳期间持续检查；每点三帧与双通道PL频谱保存实际位置、目标、帧序号、时间和原始文件哈希。控制器报警、暂停、采样超时或位置变化中止扫描。

多模态视图仍使用原导航和鼠标逻辑。计算结果的完整频谱保存在导出记录，图中曲线仅为缩略。板卡、原始包与处理结果来源必须一致；缺少正常参考时缺陷页等待输入。

神经补帧演示提供两种场景，实际整数网络预测权重并影响RGB。它展示算法功能，播放节奏不作为板端性能测量。

新完成扫描原子发布到原EMI、谱线、频率立方体。两板热像/融合板面可直接点选原始温度；新鲜USB和扫描ADC以同一新包记录来源。PC端“保存扫描配置”改变实机计划，历史6点回放不冒充新路线测量。
