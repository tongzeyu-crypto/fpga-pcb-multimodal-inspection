# 第三方与资源

本提交不包含 XoFTR、SwinFuSR 或其权重。两个网络权重由本目录训练工具产生，原始采集、增强和渲染监督的边界见训练记录。

- `runtime/display/third_party/turbojpeg.h`：保留 libjpeg-turbo 原始版权及许可证注释；显示预览通过板端动态库加载，正式 JPEG 预览需目标系统兼容实现。
- `resources/factory`：来自原有开发板资料的最小 PS 预设和 DVI RTL，保留原始文件及其注释；Vivado 生成的 IP 与软件工具没有打入提交源码。
- `graphics`、原生显示头文件、USB/机构采集源码、可选 `runtime/aoi`：从本项目已有源代码白名单复制并在提交目录独立修改，原目录保留。`runtime/aoi_rules.py` 是独立的通用规则入口，`runtime/aoi` 保留原板型规则源码供有对应先验配置时使用。
- 字形和光标：仅提取已有程序图集中的对应区域，不带历史照片区域，不复制电脑字体文件。
- 训练依赖：PyTorch、NumPy、OpenCV；运行数值处理依赖见 `runtime/requirements.txt`。其许可文件由对应发行包提供，本提交不重新打包电脑 Python 环境和开发工具。
- 运行依赖见 `runtime/requirements.txt`，顶层许可原文保存在 `resources/licenses`；不把电脑依赖库的二进制文件打包。电脑演示所需的两个可执行程序、测试源码和构建工具随完整包提供。
- 设备树公共依赖：`resources/kernel-dts/zynq-7000.dtsi` 原样来自 [Xilinx Linux v2020.2](https://raw.githubusercontent.com/Xilinx/linux-xlnx/xilinx-v2020.2/arch/arm/boot/dts/zynq-7000.dtsi)，保留 GPL-2.0+ 标识及 Xilinx 原版权注释；SHA256 为 `d8613c281acc7c2bb7248e93dd9cbccbe75df7f684fa33211de1338c1f30d593`。自定义演示设备树从本项目此前独立工程的候选源码调整而来，没有从当前自启动镜像提取或改写内容。
- 预建模型：保留项目已有 GLB、几何说明和命令网格，属于几何先验。纹理与热像叠加从经校验的当前原始记录生成；高度不视为测量值。

原始元数据保留采集来源、时间、机械位置、配置、历史路径字段与哈希，便于溯源；运行时不依赖这些历史电脑路径。`data/derived` 和 `evidence` 内的复算结果、图片、仿真向量仅为离线证据，正式入口不会以它们替代新的分析。

提交包按白名单选取文件，并扫描私钥/令牌特征。没有复制 SSH 配置、IdentityFile、`board_*_key`、电脑推理服务、JTAG broker、开发工具缓存或整套历史运行目录。私钥文件不得作为后续手动补包内容。
