# 轻量神经补帧

当前实现为“深度重投影 + 学习式像素融合”。网络已经实际参与新画面的 RGB 合成，原来的帧可信度分类器保存在 `models/frame-confidence-legacy`，不再作为当前补帧模型使用。

## 算法

1. 使用已完成渲染的颜色、深度、对象 ID 和源/目标视角，将几何像素重投影到中间视角，得到候选 A。
2. 仅根据候选 A 的有效几何邻域修复小范围空洞，得到候选 B；此步骤不读取目标视角的真实颜色或深度。
3. 小型 CNN 输入空洞比例、深度边缘、两候选的颜色差和运动幅度，输出 80×45 的融合权重。每个网格对应 16×16 个显示像素。
4. 网络输出经 sigmoid 和 8 位权重转换，逐像素计算 `RGB = ((255-a)*A + a*B + 127) / 255`。全屏输出仍为 1280×720。

权重由完整固定点渲染画面的 RGB 重建误差训练，不再使用“该区域可信/不可信”的分类标签。训练使用 48 个视角对，验证使用另外 12 个视角对，覆盖三维 PCB 和机械 EMI 地形；两组来自相同的既有几何/数据来源，不代表独立实拍泛化能力。

模型为两层 3×3 卷积，实际通道剪枝从 369 参数降到 185 参数，并导出 INT8 权重。输入和输出尺寸与原有小型共享卷积引擎兼容。PL 任务 2 执行网络各层；PS 负责重投影、邻域候选构造、sigmoid、RGB 融合和界面叠加。

## 主程序演示

运行根目录 `start_demo.cmd`，打开 http://127.0.0.1:8698/ ，点击“神经补帧”，再点击“生成补帧演示”。可选择三维 PCB 或 EMI 地形。

每个场景生成四组过渡帧，可播放“完整渲染 → 神经生成过渡帧 → 完整渲染”，也可查看神经生成帧、关闭网络后的重投影、同视角完整渲染参考和网络贡献差异。网络在本机使用实际训练权重进行 C++ 整数推理，运行不需要 PyTorch 或编译器。播放节奏用于功能展示，不是板端 FPS 测量。

## 验证记录

- 12 个保留视角用例的 C++/Python 整数结果一致；网络权重实际决定 RGB 输出，关闭权重和设为固定权重的消融对照通过。
- 新权重在现有 PL 引擎的逐层 RTL 仿真通过；具体报告见 `evidence/rtl-verification.json`。
- 完整误差对照见 `evidence/neural-frame/result.json`。受影响区域的平均 RMSE 从 8.098 降到 6.076，平均 MAE 则从 1.403 上升到 2.214，说明该轻量原型没有在全部画质指标上改善。
- 原生 ARM 显示程序已接入学习式融合，保留小角度、同场景、覆盖率和每完整帧最多一次插入的限制；失败时重新完整渲染。
- 文字、光标和交互拾取继续使用独立界面/完整渲染数据。生成像素只用于显示，不进入温度、频谱或缺陷分析。
- 实板已执行PL任务2，3600个INT8输出与整数参考一致；主程序经 `single_plane_pl_blit` 呈现中间帧，准备及显示记录约1.34 s。原自启动镜像保留。

## 重现

训练：`tools/train_neural_frame.py --work <英文工作目录> --assets <已生成的原生显示资源> --cxx <本机C++编译器>`。

像素与整数对照：`tools/verify_neural_frame.py` 使用同样的三个参数。主界面功能检查为 `tools/verify_frame_demo.py`；RTL 检查仍使用 `tools/verify_rtl.py`。

视频和技术说明可采用：系统使用深度重投影与轻量神经像素融合生成中间显示帧，网络预测区域融合权重并参与 RGB 合成；已完成算法展示、共享计算引擎RTL验证及实板PL推理与显示接入。
