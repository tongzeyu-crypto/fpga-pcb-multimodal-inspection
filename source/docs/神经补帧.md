# 深度重投影与学习式帧融合

按当前固定报告第65、66、95、98段实现：使用上一完整帧的颜色和深度，在目标视角重投影得到候选 R；P 直接使用上一完整帧。输入四个通道依次为横向运动、纵向运动、深度边缘和有效区域，占用80×45网格。

4→4→1两层3×3卷积网络预测区域权重。PL共享卷积核执行INT8层，PS执行Sigmoid，并将权重双线性插值至1280×720，按 `(alpha*R+(255-alpha)*P+127)/255`（R为重投影候选、P为上一完整帧，alpha取0..255） 合成RGB。空洞保留上一完整帧像素。板卡、数据、图层变化，覆盖不足或超出支持的视角变化时重新完整渲染。

训练使用48组视角、12组验证视角，以目标完整渲染RGB为监督；通道剪枝由369参数降至185参数，再导出INT8。两组均来自现有几何和数据，验证范围为这些渲染场景。

原界面的“神经补帧”支持网络开关、完整渲染、仅重投影、网络融合、融合权重和输出差异。电脑入口执行相同权重的C++整数参考，板端提交PL任务2。生成像素仅用于显示，不进入温度、频谱或缺陷判断。

12个验证视角完成整数与RGB合成对照，逐层RTL通过；孔洞回退和双线性权重放大也已检查。误差与单项验证范围见 `evidence/neural-frame/result.json`。提交方提供的2026年11月4日《对照分析报告》记录本版帧融合网络已完成板端验证；该报告没有给出板端加速比或帧率提升数据，本页不扩写此类指标。

当前展示权重为 α_R。旧存储logit在输出端互补，等价于把原来的“上一帧权重”改为“重投影权重”；原训练历史保留，未声称重新训练。
