# 图片来源

`photos/`为项目实物照片的公开副本，已去除EXIF，来源为2026年10月30日报告补图归档。`diagrams/`为项目报告自制图，`screenshots/`为2026年10月30日板端历史资源渲染截图。

系统图表示总体模块关系，采集调试与板端渲染的版本范围见[状态说明](../STATUS.md)。截图里的三维热融合与频率立方体属于历史数据展示：DCDC曾使用板面显示映射，原测量坐标以examples为准；STM32 EMI含模拟背景。五处AOI候选图来自电脑直采照片的离线回归。本目录图片按各自来源解释；本版整机上板验证结果见[对照分析报告](../source/docs/修复核对.md)。

未纳入尚未选定的海报、产品宣传图、外部行业视频及其他项目的相机资料。[manifest.json](manifest.json)保留发布资产与来源文件哈希，来源以集合名与文件名表示。

`board-20261103-main.jpg`与`board-20261103-scan.jpg`摘自11月3日交付包的实板演示记录。前者对应PL显示，后者对应模拟运动和历史数据回放；记录范围见[历史板端记录](../docs/history/earlier-board-record-20261103.md)。11月4日提交方报告补充了本版后续上板验证结果，完整范围见当前《对照分析报告》。

PDP3最终程序的当前界面截图按来源位于 `source/evidence/demo-integration/` 与 `source/evidence/report-scan-ui/`，属于包内电脑集成检查材料；旧板端照片按其原版本保留。
