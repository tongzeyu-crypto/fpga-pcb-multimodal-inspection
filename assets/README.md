# 图片来源

`photos/`为项目实物照片的公开副本，已去除EXIF，来源为2026年10月30日报告补图归档。`diagrams/`为项目报告自制图，`screenshots/`为2026年10月30日板端历史资源渲染截图。

系统图表示总体模块关系，采集调试与板端渲染的版本范围见[状态说明](../STATUS.md)。截图里的三维热融合与频率立方体属于历史数据展示：DCDC曾使用板面显示映射，原测量坐标以examples为准；STM32 EMI含模拟背景。五处AOI候选图来自电脑直采待测图的离线回归。图像均不作为完整实时采集和AI上板成功的证据。

未纳入尚未选定的海报、产品宣传图、外部行业视频及其他项目的相机资料。[manifest.json](manifest.json)保留发布资产与来源文件哈希，来源以集合名与文件名表示。

`board-20261103-main.jpg`与`board-20261103-scan.jpg`原样摘自本次正式代码包的实板证据。前者为实际PL显示记录，后者为板端模拟运动/历史数据扫描回放；对应验证范围见[实板记录](../source/docs/实板演示记录-20261103.md)。这些是交付包中的既有记录，本次发布没有新做硬件试验。
