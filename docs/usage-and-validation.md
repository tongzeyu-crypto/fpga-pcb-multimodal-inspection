# 现有使用方式与阶段验证

11月3日正式代码及当前运行方法见[代码提交说明](code-submission.md)，最新板端状态见[实板记录](../source/docs/实板演示记录-20261103.md)。以下是10月30日历史显示包的使用与验证记录。

本批材料可直接在GitHub浏览。先读README与功能状态，再查看报告、硬件照片和原始数据。CSV可用常见表格工具查看，NPZ为NumPy压缩数组；本页保留旧版本操作说明；新包构建入口已随[source](../source/README_GITHUB.md)收录。

2026年10月30日的稳定显示包已持久化启动。用户完成真实断电上电，确认“已自动进入界面，鼠标正常”。该包通过HDMI 1280×720独立显示，USB鼠标可拖动旋转、滚轮缩放、选择测点和切换板卡。主要入口包含三维融合、二维融合、EMI地形、频率立方体、焊接缺陷、RGB、热像与EMI测点矩阵，两块板共16页。

板端记录55个交互检查点；两个三维场景的PL绘制任务分别为37.52 ms与41.92 ms。计时只覆盖对应PL绘制任务，不能换算为整个应用、采集处理链或JPEG预览的端到端帧率。源码归档与原厂固件备份不在本批材料中。

采集证据来自另一阶段的USB和ADC调试运行；历史“仅RAM启动”是持久化前的过程记录，不能覆盖后来的冷启动确认。11月3日新包已提供数据入口与AI实现，其实板范围按单独记录阅读，不能用旧显示包验收替代。
